# [expert-500] Исправленный протокол повторного пилота

Дата: 4 октября 2026. Это изменение измерительной обвязки после отрицательного
[пилота V1](EXPERT500_PHASE1_V1_2026-10-04.md). Повторный пилот завершён:
[алгоритм4/62, эксперты1/62](EXPERT500_PHASE1_V2_2026-10-04.md), два submitted
и восемь таймаутов. Допуск не пройден; партии по50 и HELDOUT150 не запущены.

## Что исправлено

- Навигационный ответ содержит одно действие и короткое наблюдение. Полные
  факты и Q0–Q6 сдаются один раз, в конце исследования.
- Источник и календарная дата факта берутся из того же успешного сохранённого
  действия. Значение, название программы/стипендии и восемь полей области
  действия объявляет эксперт; отсутствующие данные не дополняются из запроса.
- Цитата ограничена600 символами. Тип значения сохраняется, включая false.
  Вопросы с противоречащими значениями или областями остаются unresolved.
- Все селекторы, включая тайм-ауты, измеряются. Незавершённый текст не
  принимается как ответ. Чтение сохранённых страниц, разбор и проверка полной
  трассы также включены в активный счётчик.
- Контролируемые сетевые действия прекращаются на75-й активной секунде;
  оставшееся время предназначено для сдачи и проверки фактов. Любое превышение
  общего лимита120000мс лишает запуск допуска, даже если трасса структурно верна.
- Запрошенная модель закреплена: `gpt-6-astra`. Используется уже установленная
  с приложением CLI0.159.2. CLI0.147.0 не поддерживала эту модель; этот отказ
  обнаружен нейтральной проверкой до университетских запросов.
- Схема ответа адаптирована к API: неподдерживаемая аннотация `format=uri`
  удалена только из внешней JSON-схемы. Локальный HttpUrl по-прежнему отклоняет
  относительные, FTP, javascript и некорректные адреса.

Другие экспертные каталоги, репозиторий, эталон, память и история закрыты.

Свежие10 контрольных запусков main-приложения и10 независимых экспертов,
максимум3 одновременно, под одним новым замороженным harness SHA. Приложение
сохраняет дерево `53d57225bb16867ccc0de5f961d8870dbab7b9ce`, равное текущему

всех десяти трасс сначала проверяются настоящие raw logs и фиксируются хэши;
только затем оценщик открывает эталон для нового сравнения62 фактов.
Партии по50 разрешены только после полного допуска протокола и минимум40/62.

## Проверка перед первым экспертом

Десять новых контрольных поисков завершены на harness SHA
`9421884465cbc986ce0ab017102126731fe2589d`, без429. Независимая проверка исходников
нашла пропуск tool_policy при resume и недостаточную связь координат отдельных
фактов/сводного результата с seal. До первого экспертного запроса исправлены
только родительские скрипты: политика сохранена, каждый факт (включая OTHER)
отдельно проверяется по raw source и сохраняет координаты; допуск считается
из запечатанных результатов, а весь постоянный provenance входит в seal.
Исходный JSON проверяется до потери повторяющихся полей. Очередь подтверждения
программ не выдаётся за полную историю обнаружения кандидатов.

12 проверок оркестратора и7 проверок отчёта проходят. Прежний manifest сохранён
отдельно; actual v2.1 скрипты/хэши записаны до запуска экспертов. Приложение и
CI-контроллер остались неизменными; tag `expert500-phase1-v2-2026-10-04-9421884`
закрепляет ровно тот же harness для экспертных чтений. Повторять контрольные
университетские запросы из-за исправления передачи метаданных не требуется.
