## 3. Наименьший связный рабочий UI

**Find → requirements/evidence → Plan → Preparation → original practice → saved progress.** Один новый screen с внутренними режимами Goal / Practice / Progress; вход из Plan и exam requirement блока ResultDetail. Учиться можно и при временно недоступном поиске: существующие goals/attempts доступны по saved case; личный target вручную явно обозначен как личный, не university requirement.

1. **Выбор цели.** По approved+maybe из текущего case показать exam cards: например IELTS Academic overall + каждый опубликованный band, SAT policy/total; рядом программа, intake, источник, проверка и профильный балл. Unknown/waiver/test-optional/alternative English exams остаются различимыми. Не назначать одновременно IELTS и TOEFL только потому, что оба встречаются; пользователь выбирает допустимый track. TOEFL/ACT/DET пока показываются как неподдерживаемые для практики, но их требования не исчезают. Goals нескольких программ остаются отдельными; не брать максимум чисел разных purposes/scopes.
2. **Задачи плана.** CTA «Добавить подготовку» создаёт backend goal для saved profile: exam/section, linked result + evidence snapshot, user target, planned retake, выбранный короткий practice set. Сохранение подтверждается только ACK; pending/error/retry видимы. Дата экзамена — entered/planned, дедлайн подачи — verified programme fact, календарь и длительность подготовки не придумываются.
3. **Первый контент.** Три небольших версионированных авторских пакета: IELTS Academic Reading с оригинальным passage и ключом/объяснениями; SAT Math; SAT Reading & Writing. Мини-урок → 5–10 original questions → Submit → правильный ответ и объяснение → повторить ошибки. Это честно ограниченный старт, не полный IELTS/SAT mock/course. Writing/Speaking/Listening не объявлять готовыми: можно добавить original writing prompt + self-review позже, без выдуманной band grading. Никакой автоматической внешней AI/provider оценки для первого рабочего цикла не требуется.
4. **Прогресс.** API сохраняет in-progress answers/attempt, content version, submit ACK и objectively marked result; resume после reload/relogin/другого устройства. UI показывает «2 из 3 наборов выполнено», correct/total конкретного набора, history и «следующий набор». Это практика, не официальный IELTS band/SAT scaled score, admission readiness или вероятность. Официальные academics не изменяются по результатам упражнений; новые реальные scores пользователь вводит отдельно в Profile.

**Минимальный patch scope будущего автора:** App.tsx route/hash gate/render + i18n label; небольшой ExamRequirementCard в ResultDetail; Plan CTA/task summary; один PreparationScreen; typed DTO/client methods; один case-scoped preparation hook/state; Billing entitlement/copy из backend. Home может получить дополнительный «Continue practice» после реального attempt ACK, без замены существующего research recovery next-step. Не расширять Documents ticks или record<string,unknown> Profile draft в хранилище уроков.

## 5. Смысловые проверки перед реализационной приёмкой

Существующие controls сохраняются: JourneyScreens Plan labels/queued documents, BillingScreen35–55 server pricing/quota, ComparePanel.preparation75–178 document evidence, ProfileLists.runtime55/77 retakes, native journey142 IELTS per-section, draftIdentity50–171/logout/stale-owner и ProfileScreen.feedback21–79 ACK/error/retry. Они не доказывают новый курс.

Новые необходимые tests:

- exact linked exam evidence: overall MET + writing GAP; missing subscore PENDING; unknown vs locked; waiver/test-optional vs required; stale/conflicting/wrong intake/purpose не превращаются в confirmed goal;
- empty/no programmes → manual personal target; approved+maybe на своём case → Plan goal → требуемый pack; remove/re-run result не теряет историю и не меняет target/evidence молча;
- unlimited/null/exhausted/expired subscription, one-off full case без prep right, foreign case403, provider failure — entitlement UI следует серверному prep flag, lesson не расходует case quota;
- original pack/key/content version; объективный correct/total; submit idempotency; failed save/submit retains text/answers + explicit retry; no official academics mutation или fake band/score;
- reload/relogin/server history, same-case redraw retains session, A→B delayed response refused, logout/org switch/stale tab denied, deletion removes proper prep data;
- one native synthetic E2E: choose programmes → evidence goal → entitled practice → feedback → reload progress; keyboard labels/focus/errors + reduced motion. Реальные provider/accounts и остановленный поиск для этого не нужны.

**Итог:** существующий matching/profile/Plan даёт основу; подготовка пока не реализована. Рабочий первый релиз требует явного server entitlement, typed exam evidence и сохранённых attempts вместе с небольшим оригинальным контентом. Одни новые карточки/проценты/marketing.includes такой релиз не выполняют.
