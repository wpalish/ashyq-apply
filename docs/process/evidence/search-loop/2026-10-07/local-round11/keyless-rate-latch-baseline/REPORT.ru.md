Минимальные требования будущего отдельного исправления: единый typed predicate только для explicit HTTP429/explicit RATE_LIMITED; сохранить исходные status и fixed enum reason в process-local refusal record, включая statusNone, без arbitrary vendor text; подавлять новые HTTP initialize/notification/tool dispatches у повторного и нового factory adapter; прекращать дальнейшие original query families без ложного HTTP429 сообщения и без зарядки неисполненных families. Локально отвергнутая уже вызванная query seam остаётся попыткой, а не vendor dispatch. Не лачить обычные transport/timeouts только по факту SearchUnavailable. Внутренний source-default retry=True наблюдает первый meta refusal раньше наружного factory catch; правило «ни одного tool call после первого _meta refusal» не обеспечивается одной наружной latch правкой. Retry semantics должны быть отдельно явно решены owner, без расширения budget/timeouts или скрытого изменения default.
