## Приоритетное минимальное следующее правило

Первый reader experiment: **IELTS prose ownership**, defaultFalse. Его ограниченная цель — разрешить IELTS overall/subscore только из одного IELTS-owned sentence/block; не запускать общий `extract_requirements` на произвольной topic page. Никакого university/path/acronym hardcode.

Уже существующий table reader привязывает IELTS к row headers и не делает каждый test row IELTS по caption. Проза требует такого же владения: явный IELTS label в той же sentence или ближайший semantic test heading; boundary закрывается равным/старшим heading, следующим test heading и explicit section/article/accordion-item region. Nav/aside/chrome headings не могут установить owner соседнему body. DOM обеих retained English pages содержит отдельные CAEL/IB/IELTS accordion blocks, поэтому это подтверждённая структура, а не необходимость угадывать экзамен по странице. Не использовать глобальный DocumentIR.section_path как единственное доказательство: текущий IR не изолирует все structural/chrome boundaries.

Число читать как полный numeric atom — без first-digit truncation60→6, с допустимым IELTS диапазоном и explicit local label. `ClaimBuilder.page_text` остаётся исходным для contiguous verbatim checks; excerpt/section ownership и `scope.qualification/population/year` берутся только из этого блока плюс действительно общей explicit admission scope. Соседние IB/CAEL/TOEFL qualifications не наследуются. Отсутствующая/relative/old year остаётся unknown или stated old-year; запрос2027 не дополняет её. Обменные/visiting/non-degree блоки остаются исключены существующим full-degree guard.

Перед promotion нужны эти содержательные controls: retained CAEL/IB-before-IELTS→correct IELTS-owned provenance и unknown qualification; CAEL-only6.0 и CAEL60 не создают IELTS; IELTS→TOEFL sibling не продолжает owner; explicit sibling region и sidebar IELTS heading не наследуются; actual contiguous IELTS sentence сохраняется; неизвестный год и обменный/другой audience не превращаются в full-degree2027 proof. Сейчас этот rule **не реализован и не признан безопасным**: сохранён только следующий проверяемый contract.

После этого отдельно чинить deadline reader по **table/row purpose**, а не по ближайшему regex `deadline`: application table/row имеет собственные header+section+campus/programme/population/year. Document/supplementary/early-consideration/non-degree/part-time/summer/visiting rows не могут заменить main full-degree application deadline. На actual UTM bytes Jan15 main row и Feb1 document/supplementary rows раздельны. Date с неполным годом не дополняется current/requested year. Независимый маленький lexical repair для WES/ECE — whole-word boundaries; December/received не trigger, явный WES/ECE requirement сохраняется. Эти две правки не входят в первый IELTS ownership experiment.
