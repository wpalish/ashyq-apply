# Dalian: подтверждённая ранняя потеря discovery lead

Подтверждён применимый undergraduate CS programme-description lead: https://cs.dlut.edu.cn/ENGLISH/education/Undergraduate_Education.htm. Baseline, fixed repeat и прежний expert capture содержат идентичные HTML bytes, SHA-256 `1d9877beb05fcc2e63de5f94358b59f466d5b50c372f3f7c8ae4629b51717ec7`. Meta content_hash во всех трёх случаях — `cd7b0b7ffd8aae13b2bb42d43e1cea62c3c7018ca75ab3fe0b2f5e2e9489408c`, совпадает со штатным пересчётом. Baseline get#17 и repeat get#20 успешно прочитали страницу; оба trace отклонили её: `page subject 'Undergraduate Education-计算机科学与技术学院' does not match requested fields ['computer science']`.

Самая ранняя подтверждённая семантическая потеря — `page_classifier.main_content`, строки352–353: substring regex `_CHROME_HINT` (247–249) совпадает с `sidebar` у ancestor `<div class="sidebar-page-container">` и удаляет весь основной материал. Это layout wrapper вокруг article, а не отдельная sidebar. Оригинальный h2 на строке391: `Introduction to Undergraduate Training Programs in Computer Science and Technology`; в нём прямо связаны undergraduate и CS, далее идут curriculum/core courses. После pruning classifier DOM содержит лишь generic document title, без этого h2 и текста. Это воспроизводимая потеря source identity, не Chinese alias mismatch и не вывод по широкой body-подстроке.

Дальше есть отдельное препятствие: `_identity` (732–738) выбирает h1 либо document title и не использует этот содержательный h2. Даже сохранение wrapper в одиночку оставляет generic subject и field rejection. Actual `_recover_search_pages` (1776–1777) с original body воспроизведён без сети: checked1, confirmed0. Контроли в памяти: только убрать `sidebar` из layout class — heading сохраняется, confirmed0; только повысить настоящий h2 до h1 — wrapper всё ещё удаляется, confirmed0; оба изменения — confirmed1, выбран exact CS URL, academic_year=None. Контроли не меняют официальные originals и не являются production patch.

Следующий обоснованный implementation target для отдельного раунда: консервативно сохранять содержательный ancestor layout при удалении chrome в `main_content`, затем проверить приоритет explicit degree-and-field main heading при generic document title. Нельзя считать первую правку достаточной для восстановления Dalian programme selection: воспроизведение фиксирует и второе препятствие. При таком дизайне нужны отрицательные проверки nav/sidebar menus и неоднозначных/multiple programme headings; произвольное совпадение field в body не подходит.

Scope: подтверждена потеря programme-description lead для дальнейшего исследования. Страница не подтверждает exact international Bachelor award, campus, teaching language, active admission или fall2027. Classifier читает undergraduate как bachelor; отдельный production identity reader по этому title оставляет degree_level UNKNOWN, field YES, active UNKNOWN и intake UNKNOWN.
