# Actual data-flow / policy inventory

All references are current backend/app source. Runtime vendor configuration, deployment storage region, backups and real operational log settings were intentionally not opened.

| Category | Collection and primary storage | Sharing / access | Retention and deletion boundary |
|---|---|---|---|
| Account and session | Email, display name, scrypt password hash, organization/membership, opaque session-token digest, expiry/last-seen (`models/auth.py:24–40,71–122`; `security.py:151–230`). Reset digest/expiry/used marker/requested IP (`routes_account.py:182–220`, `models/auth.py:90–107`). | Account/membership APIs authenticated; reset email SMTP carries recipient and secret bearer link. Console mail logs body only in non-production permitted configuration (`mail.py:42–82`, `config.py:243–247`). | Sessions pruned on login/expiry access (`security.py:242–264`); reset records no time-driven purge found. Account deletion password-confirmed; user/sole-member organizations erased, shared organizations/cases survive (`routes_account.py:352–429`). |
| Applicant case | Display name; degree/field/intake, citizenship/residence/education/graduation; grades/test sections/retakes; activities and free-text achievements/evidence links; preferences/research_privacy; budget/family contribution; scoring weights (`schemas/profile.py:33–44,162–177,189–216,240–262,286–326`). Whole JSON in ApplicantProfileRow (`models/applicant.py:22–42`, `routes_profile.py:43–67`). | Current organization's members may access/edit/export/delete all its cases. No per-case per-user ACL is implemented; this is workspace sharing, not public sharing (`api/tenancy.py:12–39`). | No automatic applicant TTL found. Profile deletion ORM cascades runs/results/claims/conflicts; audit/jobs/entitlement exceptions remain. Own profile export is not an account-wide export of social/payment/session records (`routes_profile.py:266–398`). |
| Research/results | Run scope/settings/diagnostics/errors and retry URLs; evidence claims/conflicts; calculated fit/rank/funding gap/applicant scores; decisions, reason, notes, collected checklist (`models/research.py:27–113,116–206`; `routes_results.py:278–327`). | Owned case/run and paywall guards. No export-file persistence on these routes. | Attached rows removed with profile. Independent jobs, minimal audit and billing linkage are not covered by profile cascade; operational errors may echo rejected free-text (S2). No general applicant/run retention sweep found. |
| Transcript PDF | Authenticated multipart PDF, capped at 10MB, local pypdf thread parse; suggestions/contiguous excerpts returned, not persisted by handler (`routes_profile.py:142–209`). | Server local parsing, no OCR/LLM provider call in this handler. User must explicitly apply suggestions into profile. | Handler does not save original file; multipart parser/framework can use temporary spool storage. Do not claim the upload never exists on disk or logs/backup were audited. |
| University/government pages | Official/public URL, body/content disk cache; global metadata hashes/validators/access state and evidence excerpts (`fetching.py:177–237`; `models/source_page.py`; `jobs/source_scanner.py`). | Outbound GET exposes server network metadata/user-agent to sources. SourcePage metadata daily purge after 180 days only without active claims (`source_page.py:257–279`, `source_scanner.py:605–628`). This is not an applicant retention policy. |
| Configured search | DiscoveryIntent reads degree, first requested field, optional year; public institution/domain/population marker. Vendor response is discovery evidence, not source fact. | Vendor logs/retention/region/contract unknown; no claim of provider deletion. The requested major/intake is still a user research preference, not guaranteed anonymous. |
| LLM decision seam | Config supports none/fake/TypeSafe. TypeSafe sends a state/questions/model; link state contains field/degree and public anchors/URLs, no profile parameter (`decisions/typesafe.py:65–80`, `link_ranker.py:40–61`). | Static app-wide call-site search found no invocation of get_decision_model/rank_links outside definitions. Thus capability exists but active product path not established. `research_privacy` does not currently authorize an implemented profile-aware route. | Do not claim profile-aware LLM consent, vendor-specific model retention or active sharing from config support alone. |
| Social | Explicit join profile with user display name, city/major/status/uni interests/bio and DM policy; posts/replies/tags, block relationships, private conversation text/read timestamps; avatar sanitized JPEG/PNG bytes (`routes_social.py:196–226,739–818,1136–1173`, `models/social.py`). | Discover/feed cross tenants intentionally among authenticated accounts. DM participants only; reporting exposes an excerpt to moderators (`routes_social.py:977–1019`). No report expiry found. |
| Payment | Order/case IDs, amount/status/method, masked phone, provider invoice/QR, entitlement/subscription linkage, redacted event detail (`models/billing.py:61–144`). | Full phone only to configured ApiPay invoice endpoint; no profile grades/activity payload (`payments/apipay.py:107–134`, `routes_billing.py:166–181`). Profile-linked Order FK cascades in a correctly enforced DB; Entitlement's profile/order references are plain strings. Provider copies and statutory accounting obligations unknown; no legal conclusion. |
| Operational logs/audit | Correlation ID, request route metrics, job/run IDs, exception text/tracebacks; AuditEvent actor/entity IDs/action/detail; Job errors (`logging_setup.py:79–122`, `main.py:235–276`, `pipeline/runner.py:471–477`, `models/research.py:209–229`, `models/jobs.py:54–80`). | Server operators/log processor recipients unknown. API audit is organization scoped; job queue is owner scoped (`routes_admin.py:47–74`). | No log/Job/AuditEvent TTL found. IDs and error text are not guaranteed anonymous, and rejected URL logging is S2. Infrastructure log/backups retention and access are outside source proof. |

Policy wording must distinguish current implementation, optional configured third parties and future profile-aware features; give exact retained exceptions rather than “deletion removes absolutely all data”. Consent record version/time/provider selection is not currently represented by the stored research_privacy enum alone. No statement here determines legal basis, age threshold, regulatory compliance or residency.
