## 3. Oracle conventions

“Reject” means closed schema/domain rejection at the indicated pure boundary. HTTP codes in this report are **future route mappings**, not an assertion that a route exists or has been tested:

- Bad new client structure/value → 422 admissions_actions_input_invalid.
- A disallowed personal transition → 422 admissions_actions_invalid_transition.
- An excessive prospective current record/target union → 422 admissions_actions_limit_exceeded.
- The same invalid bytes in saved state/head/receipt → 503 admissions_actions_saved_unreadable; never reset or silently omit them.
- New malformed authorized source → 503 admissions_actions_source_unreadable; existing personal projection preserves records with evidence_unknown.
- New binding requires current owned selected metadata plus research access; existing personal operations do not require their old research target to remain available.

Command class/discriminator spellings other than the expressly frozen select_active_preparation and declared-submission provenance are implementation details. The matrix uses the frozen logical command meanings and does not invent an additional command. Caller-supplied trusted context is not evidence that a database ownership/entitlement check happened.
