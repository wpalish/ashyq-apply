# KB import from the development corpora — 2026-10-19

Live search is frozen (owner). The product answers from a verified knowledge base of the top-100
catalogue universities for the bachelor's in Computer Science
(`backend/evaluation/research/data/kb_top100_list.json`). The 21 rows with `status: "import_existing"`
already have labels in the development corpora; this import copies them into
`backend/app/knowledge/kb_imported_dev.json` (not under `backend/data`).

- Generator: `cd backend && python -m evaluation.research.build_kb_imported_dev` (deterministic, no network).
- Inputs: `ground_truth.reviewed11.json`, `dev2.draft3.json`, `dev3.draft3.json`, `dev5.draft1.json` and the
  matching `identity_bindings.*` files (award names only). No heldout file is opened.
- Test: `backend/tests/test_kb_imported_dev.py` (URL + quote on every fact, no heldout id, no model id).

## Rules of the import

1. A fact comes only from a corpus label with `status: "known"` whose evidence has a URL and a non-empty
   excerpt. `unknown` and `not_applicable` labels are not imported (e.g. `gpa` is `not_applicable` or
   `unknown` everywhere, so no GPA fact exists). Known labels without URL+quote are listed in
   `skipped_known_labels` (currently none).
2. Values and quotes are copied verbatim. Label `notes` are kept as context; agent model identifiers in
   notes are replaced by `[agent]`.
3. Label key → question:
   | question | corpus keys |
   |---|---|
   | `english` | `ielts.overall`, `ielts.subscores`, `english_evidence.*` |
   | `gpa` | `gpa` |
   | `deadline` | `deadline` (not `deadline.eu_national`: that is an EU-national answer) |
   | `tuition` | `tuition` |
   | `scholarship_exists` | `scholarships`, `scholarships.<award>.exists` |
   | `scholarship_international` | `scholarships.<award>.applicability.international` |
4. `verified_on` is the case's `review.verified_on` when signed (reviewed11 cases, 2026-10-17); for draft
   corpora it is the corpus version date (`verified_on_basis: "corpus_version_date"`). `review_status`
   says which (`human_verified` or `draft`) — dev2/dev3/dev5 entries are unsigned expert drafts.
5. Stale (`stale: true`, reason in `stale_reasons`, mirrored in top-level `stale_facts`): accessed more
   than 365 days before 2026-10-19, or academic year whose end year ≤ 2026, or a deadline date already
   passed. On this import: **0 stale facts**.

## JSON shape (`format: "kb-imported-dev/1"`)

```jsonc
{
  "format": "kb-imported-dev/1",
  "generated_on": "2026-10-19",
  "programme": "bachelor computer science",
  "applicant": "international",
  "list_version": "2026-10-19.kb-top100",
  "questions": ["english","gpa","deadline","tuition","scholarship_exists","scholarship_international"],
  "stale_policy": {...},
  "entries": {
    "<seed_id>": {                         // key = kb_top100_list seed_id, e.g. "qs2027-002"
      "seed_id": "qs2027-002",
      "source_case": "imperial",           // dev corpus case id
      "source_corpus": "dev3.draft3.json",
      "corpus_version": "2026-10-18.dev3-draft3",
      "review_status": "draft",            // or "human_verified"
      "verified_on": "2026-10-18",
      "verified_on_basis": "corpus_version_date",   // or "review.verified_on"
      "university": "...", "country": "...", "official_domain": "...",
      "programme": {
        "status": "known",
        "urls": ["..."],
        "evidence": [{"url","quote","quote_truncated","accessed_on","source_type"}],
        "related_programme_urls": ["..."]  // [] when the case has none
      },
      "facts": {                           // every question present; [] = no known answer
        "<question>": [{
          "key": "tuition",                // original corpus label key
          "value": {"amount": 47800.0, "currency": "GBP"},
          "period": null,                  // evidence scope.intake, e.g. "fall 2027"
          "academic_year": null,           // evidence scope.academic_year, e.g. "2027/2028"
          "population": "international",   // evidence scope.population
          "source_url": "https://...",
          "quote": "verbatim excerpt",
          "quote_truncated": false,
          "source_type": "official",
          "accessed_on": "2026-10-17",
          "verified_on": "2026-10-18",
          "notes": "...",
          "award": {"subject","source_url"},   // scholarship facts with an identity binding only
          "more_sources": [{"url","quote",...}], // only when the label has >1 evidence item
          "stale": false,
          "stale_reasons": ["..."]              // only when stale
        }]
      },
      "known_fact_count": 6
    }
  },
  "stale_facts": [{"seed_id","question","key","reasons"}],
  "skipped_known_labels": [{"seed_id","key","reason"}]
}
```

A loader merges by `seed_id`; a fact's identity is `(seed_id, key)`.
