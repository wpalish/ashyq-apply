# Подпись dev5 — страница программы и шесть основных вопросов — 2026-10-19

**Что подписываем.** Черновик `backend/evaluation/research/data/dev5.draft1.json`. В нём 13 университетов —
ещё одна группа «заместителей по стране» для отложенных девяти:
- Казахстан: KBTU, Satbayev, AITU;
- Турция: Hacettepe, Bilkent, YTU;
- Чехия: Palacký (Оломоуц), ZČU (Пльзень);
- Германия: TU Dresden, LMU;
- Италия: Padova, Sapienza;
- Литва: VILNIUS TECH.

Ни один из них не делит домен или головную организацию с отложенными девятью. Запрос везде один:
бакалавриат, computer science (или ближайший аналог), набор осень 2027. Сейчас ничего не подписано: все
случаи в статусе `draft`.

**Правило.** «Известно» ставится только там, где цитату дословно нашла проверка `verify_evidence` на
раннере CI:
- страницы программ: найдено 33 цитаты из 39;
- основные вопросы: найдено 49 из 50.

Всё остальное — «неизвестно», и в заметке указана причина.

**Доступ.** KBTU и Satbayev с раннера недоступны: сервер отдаёт TLS-сертификат без промежуточного, поэтому
robots.txt не читается, и по RFC 9309 весь сайт считается закрытым. Эти два случая записаны как случаи
доступа. У них только «программа неизвестна» и связанные страницы, найденные через поисковый индекс.
