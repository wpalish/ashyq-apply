## Записи и ограничения

Трасса содержит Q0–Q6: found, not_published, inaccessible либо unresolved.
Отсутствие найденного ответа само по себе не означает not_published.
Каждый found ссылается на сохранённую официальную страницу, точную цитату,
место в DocumentIR или страницу PDF, действия и опубликованную область факта.
Проверка структуры/байтов не является подтверждением семантики ответа;
все предложения остаются unreviewed до независимой оценки.

Причины пропуска записывает оценщик после сдачи экспертом трассы:
NOT_DISCOVERED, BUDGET, SLOT, CLASSIFIER, EXTRACTOR, OTHER_PAGE,
PDF, JS, SCOPE, ACCESS. Каждая причина требует наблюдаемого поля лога.

Strict-контроллер ограничивает60 cold get,120000ms и6 поисковых попыток.
Отказывает до превышения лимита; сохраняет сбои и запрещает повторный поиск
после429. Возобновление связано с raw-log hash, prefix, провайдером, доменами,
comparison mode и уже израсходованными счётчиками. Переименование запуска
не сбрасывает бюджет. Fetcher сохраняет свои robots/egress/redirect ограничения.

independent_full_budget означает отдельный свежий бюджет эксперта.
baseline_intervention продолжает бюджет алгоритма. Эти сравнения не взаимозаменяемы.
Старый benchmark не считает cache hit платным чтением: для равного сравнения
готовится отдельный opt-in strict harness с указанием своей версии.

## Действительная изоляция

Обычный субагент разделяет файловую систему с родителем и не является слепым.
Для живого пилота используется отдельный ephemeral Codex CLI:
пакет/контекст/вывод контроллера передаются на stdin, пользовательская
конфигурация и project instructions отключены, shell/MCP/browser/memory
и прочие исполнительные инструменты отключены. macOS Seatbelt запрещает
чтение и запись репозиториев, эталона, истории, памяти и вложений.

Реальный нейтральный запуск модели завершился за4.104s без исполнения
инструментов; чтение публичного sentinel разрешено, закрытого запрещено
с сообщением о правах доступа. Проверяется завершение JSON event stream,
соответствие final message выходному файлу, неизвестные/tool/error события
отклоняются. Разрешено только точно известное startup-сообщение о том,
что code-mode host отключён. Запуск из закрытого cwd не работает;
процесс должен стартовать в собственном разрешённом каталоге.

Raw pages/events остаются в ignored artifacts. Это доказательство
изоляции нейтрального запуска, а не результат проверки университетов.
