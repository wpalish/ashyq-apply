## Критический путь и сроки (оценка по стене)

01 (знаменатель) → 03 (строки, ~1 рабочая сессия) → приземление воркеров A–D и 06 (каждое правило ≈ 25 мин × 4
набора; параллельно) → подпись 02 → 16 (остаток) → 17 (один прогон по умолчанию, ~25 мин) → 19 (один прогон
девятки, ~25 мин). Самое длинное звено — работа воркеров C и D по доказательствам (несколько парных прогонов
каждый); укоротить его можно только одним способом — **не ставить за ними новых правил**, поэтому 16 называет
остаток до любого нового правила по доказательствам. Билеты 07/08/09/10 повышают честность целей 4 и 6, но на
критическом пути стоят только если 17 провалится по цели 4.
