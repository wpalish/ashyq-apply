## Критический путь, порядок по выигрышу на час, остановка

**Критический путь**: 02 → 03 (ваша подпись dev5) → 14 (baseline dev5, слепо) → расчёт «без одной страны» (13) → 15.
Самая длинная цепочка по стене: 07 → 09 → пять парных прогонов → вердикт (≈ 8–10 ч) — поэтому 07 стартует в первый час.

**По ожидаемому выигрышу на час воркера**: 05 (1–2 ч, без прогона; может объяснить большую долю «gold не возвращён» и
сказать H-2, что проверять) → 06 (2 ч + прогон; путь — единственный структурный факт, верный для всех девяти и ни для
одного development-набора, кроме когорты) → 07 (2 ч + четыре прогона; воспроизводит отказ № 2 на 44 кейсах) → 02 + 03
(единственный путь к чистому предсказателю) → 11, 12 (офлайн, по 2 ч) → 10, 08 (офлайн, 2–3 ч) → 14 → 09 (единственное
правило, которое карта ожидает построить) → 04 → 16, 13, 15, 17.

**Остановка**: передача пре-регистрации при (а) dev5 подписан и промерен слепо; (б) у H-A…H-F есть вердикт с
числами; (в) на рукаве «gold выбит» неверных подтверждений 0 на каждом наборе без потери попаданий на обычном рукаве;
(г) каждое правило, включённое с 17.10, прошло защиту от «виденных сайтов» или выключено; (д) разброс «без одной
страны» по dev4 + dev5 сам ≤ 15 п.п. Иначе — эскалация с реестром остатка (17) после 15 часов или двух провалов правила
на одной причине. Эта карта **не тратит взгляд на девятку**; она пишет пре-регистрацию для одного.
