# Вопросы владельцу — карта «Поиск страницы программы на незнакомых университетах»

Дата: 2026-10-18 · Карта: `map.md` · Билеты: `issues/` · Составил claude-opus-5. Агент только рекомендует;
решения — ваши. Ничего из heldout-девятки не открывалось; все факты — из трёх development-наборов и кода.

**Как отвечать.** По номеру билета и вопроса: `01-Q1 да`, `01-Q3 нет: …`, `02-Q5 обсудить`. «Да» принимает
рекомендацию как написано. «Нет» или «обсудить» по любому вопросу открывает отдельный раунд по этому билету;
остальные не ждут. Полный текст каждого вопроса — в файле билета.

## Пункт назначения (черновик — подтверждается билетом 01)

Одобренный вами **дизайн поиска страницы программы, v3**: упорядоченный список правил под флагами — у каждого
защита точности и development-кейс, который его мотивирует; изменения в измерениях, которые loop'у нужны до
правил; протокол приёмки для следующего прогона heldout-девятки. Такой, чтобы цели DoD 3 («страница программы
найдена на каждом читаемом сайте; сайт, который нам отказывает, честно отмечен *unavailable*, никогда не
угадываем») и 6 (heldout в пределах 15 п.п. от когорты) были достижимы без единого правила, подогнанного под
девятку. Дизайн передаётся loop'у (`loop-engineering`, парные прогоны, ваше одобрение на каждое правило);
сама карта ничего не строит.
