# Новая цель Unimatch — 11 октября 2026

Завершить поисковик и добавить подготовку к вступительным и языковым экзаменам в подписку. Пользователь выбирает страны/программы, получает требования с официальными источниками, видит свои пробелы и проходит занятия/практику с сохранением прогресса.

## Первая рабочая часть

-IELTS Academic и Digital SAT: оригинальные стартовые занятия и упражнения.
-Расширяемый каталог TOEFL iBT, DET, HSK, CSCA и других экзаменов. Неготовые курсы не объявляются доступными.
-Требования по программе/уровню/циклу/языку/условиям освобождения. Overall не заменяет компоненты; альтернативы не означают «сдать всё».
-Доступ к подготовке по действующей подписке; практика не тратит квоту вузов и не запускает поиск.
-Попытки и прогресс хранятся на сервере в своём кейсе, переживают обновление/смену устройства, экспортируются/удаляются с кейсом. Учебные баллы не заменяют сертификаты.

## Граница готовности

Первый increment не является полными IELTS/SAT/HSK курсами. Writing/Speaking без проверенной экспертной оценки не получают band. Нет гарантий/вероятностей поступления. Официальные чужие задания не копируются; даются ссылки на разрешённую практику. Цены/полные курсы/production launch остаются отдельными работами. Поиск и его STOP/неизмеренная полнота не объявлены закрытыми.

## Приёмка

Связь программы с экзаменом и источником; сохранённая попытка и обратная связь; изоляция кейсов; истечение подписки; quota неизменна; export/delete; native tests и миграция SQLite/PG; сквозной local UI, затем отдельный release.

Цель зафиксирована здесь: механизм второй цели приложения отказал из-за незавершённой первой; первая не помечена завершённой.
