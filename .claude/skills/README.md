# UniMatch project skills

Four skills extracted from building UniMatch. They encode the judgements that
this domain punishes you for getting wrong.

| Skill | Use it when |
|---|---|
| `university-admissions-research` | Verifying entry requirements, deadlines, test policies or document lists |
| `scholarship-audit` | Classifying an award, comparing funding, or computing what remains to pay |
| `applicant-fit-scoring` | Ranking a shortlist, or explaining why one option beats another |
| `loop-engineering` | Building an MVP end to end, or hardening a system against known failure modes |

They are project-scoped. To use them everywhere:

```bash
cp -r .claude/skills/* ~/.claude/skills/
```
