# analysis/ — аудит и дизайн подбора для ASHYQ Apply

**Начинать отсюда → `AI_TASK_BRIEF.md`** — самодостаточное задание для ИИ-агента или разработчика:
контекст, принятые решения, формулы, задачи по этапам, тесты, критерии готовности.

| Файл | Что это |
|---|---|
| `AI_TASK_BRIEF.md` | **Задание для исполнителя.** Весь контекст обсуждения и все решения в одном файле |
| `SPEC_matching_v2.md` | Детальная спецификация v2 — формулы, схемы, промпты, API, тесты, план. Источник истины при расхождениях |
| `ANALYSIS.md` | Аудит текущего алгоритма: как устроен, экспериментальные доказательства проблем, варианты |
| `DESIGN_agentic_search.md` | Обоснование агентного поиска: роль ИИ, приватность, рейтинги с весами, Reddit/community |
| `reference/ranking_v2.py` | Исполняемая референс-реализация формул; прогоняется на сохранённом демо-прогоне |
| `scripts/01..03_*.py` | Эксперименты чувствительности текущего (v1) алгоритма |

Запуск референса (после `alembic upgrade head` и `seed_demo.py` в `backend/`):

```bash
cd ashyq-apply/backend
UNIMATCH_DEMO_MODE=true ./.venv/bin/python ../analysis/reference/ranking_v2.py
```
